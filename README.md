Pokepedia

Una enciclopedia Pokémon con Pokédex, información detallada y herramientas para explorar el universo Pokémon.

Página web: "Visitar Pokepedia" (https://alexarielaguirreortega-eng.github.io/pokepedia/)

---

Sobre el proyecto

Pokepedia es una página web dedicada al universo Pokémon. Su objetivo es reunir información de Pokémon, movimientos, habilidades, objetos, regiones, personajes y mucho más en un solo lugar.

El proyecto busca ofrecer una experiencia sencilla e intuitiva para consultar información, descubrir Pokémon y utilizar diferentes herramientas relacionadas con los combates y la creación de equipos.

Es un proyecto de fans, sin afiliación oficial con Nintendo, Game Freak o The Pokémon Company.

Características principales

Pokédex

- Exploración de Pokémon.
- Búsqueda de Pokémon.
- Consulta de información y características.
- Acceso a información individual de los Pokémon.

Base de datos

La página reúne diferentes categorías de información:

- Tipos Pokémon.
- Movimientos.
- Habilidades.
- Objetos.
- Bayas.
- Regiones.
- Gimnasios y Liga Pokémon.
- Personajes.
- Pokémon legendarios y míticos.

Herramientas

Pokepedia también incluye herramientas para analizar y organizar información:

- Team Builder: creación y organización de equipos Pokémon.
- Comparador: comparación entre Pokémon.
- Rankings: consulta de clasificaciones.
- Generador aleatorio: generación de elementos aleatorios.
- Calculadora de tipos: consulta de efectividades entre tipos.
- Calculadora de daño: herramienta para analizar el daño de los combates.

Funciones personales

- Sistema de favoritos.
- Historial de Pokémon vistos recientemente.
- Almacenamiento local de favoritos, historial y equipos en el navegador.

Tecnologías y datos

El proyecto utiliza datos de "PokéAPI" (https://pokeapi.co/) para obtener información relacionada con el universo Pokémon.

Los datos de PokéAPI se distribuyen bajo la licencia Creative Commons Attribution 4.0 (CC BY 4.0).
